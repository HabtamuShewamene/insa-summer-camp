# Insa Summer Camp Challenges

This repository collects several small projects and coding challenges completed during the summer camp. Each challenge focuses on a different programming concept and implementation style.

## Challenge Overview

### 1. Challenge 1 — Environment Proof Script
Location: [challenges/challenge-1](challenges/challenge-1)

This challenge implements a simple Python script that prints:
- the participant name
- the current date
- the installed Python version
- the installed Node.js version

It is a lightweight environment-check exercise that helps verify the local setup.

### 2. Challenge 22 — Task API
Location: [challenges/Challenge22](challenges/Challenge22)

This challenge implements a Node.js and Express-based task management API. It includes:
- authentication and user handling
- task routes and business logic
- middleware and validation
- configuration and database/store modules
- Git workflow practice materials and challenge documentation

It is designed as a realistic backend service exercise with a strong focus on Git and repository maintenance.

### 3. Challenge 3 — Personal CLI Toolbox
Location: [challenges/challenge3](challenges/challenge3)

This challenge implements a small Python command-line tool for managing personal notes. It supports:
- adding notes
- listing notes
- deleting notes

Notes are stored in a JSON file, making it a simple but practical CLI project.

### 4. Challenge 4 — Authentication System
Location: [challenges/challenge4-authentication system](challenges/challenge4-authentication%20system)

This challenge implements a full-stack authentication platform with:
- a NestJS backend API
- a Next.js frontend interface
- JWT-based authentication and refresh tokens
- password strength validation
- brute-force protection and suspicious login detection
- session management and security event tracking
- Google OAuth integration

It is the most complete project in the repository and covers modern authentication and security concepts.

## What These Challenges Cover Together

Collectively, these challenges introduce and practice:
- Python scripting and CLI development
- Node.js and backend API design
- authentication and security principles
- full-stack application structure
- Git and project documentation workflows

## Suggested Order to Explore

1. Start with the environment proof script for a simple introduction.
2. Review the CLI notes tool for basic Python command-line programming.
3. Explore the Task API for backend routing and middleware concepts.
4. Study the authentication system for a full-stack security-focused implementation.
